# ADR-0010: C++20 in every repository

- Status: Accepted
- Date: 2026-11-03

## Context

Six repositories were C++17 and the rest C++20. The standard relies on C++20: `requires` expressions for optional
port hooks, concepts for port constraints, `std::span` for caller buffers, designated initialisers for configs.
ESP-IDF 5.x and current STM32 toolchains support C++20.

## Decision

Every repository builds as C++20 (`target_compile_features(<target> PUBLIC cxx_std_20)`, `Standard: c++20` in
`.clang-format`). Public headers may use any C++20 language feature the pinned ESP-IDF GCC and the CI clang both
support; library features are limited to the freestanding-friendly headers listed in [layers.md](../layers.md#includes).

## Consequences

- One feature set for every repository; `void_t` detection and SFINAE tricks are replaced by `requires`.
- Users of a driver need a C++20 compiler.
- The six C++17 repositories move up, which is compatible for callers already on C++20.
