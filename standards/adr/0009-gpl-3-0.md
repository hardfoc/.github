# ADR-0009: GPL-3.0 in every repository

- Status: Accepted
- Date: 2026-11-03

## Context

Every HardFOC repository was GPL-3.0 except `hf-sfm-flow-meter-driver`, which was MIT. Mixed licences complicate
the aggregates and the firmware, which combine every driver into one binary.

## Decision

Every HardFOC repository is licensed GPL-3.0, with the GPL-3.0 text in `LICENSE` and `GPL-3.0` in
`idf_component.yml` and the README. `hf-sfm-flow-meter-driver` is relicensed from MIT to GPL-3.0.

## Consequences

- One licence for the whole stack and every firmware image.
- Code copied in from elsewhere must be GPL-3.0 compatible; third-party code keeps its own licence in
  `third_party/` with its notice.
