# Code of conduct

The HardFOC project adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. It applies to all `hardfoc` repositories, issues, pull
requests, discussions and any other project space, and to anyone representing
the project elsewhere.

In short: be respectful, assume good faith, give and accept constructive
technical criticism, and do not harass, insult or exclude people.

## Reporting and enforcement

Report unacceptable behaviour to the `hardfoc` organization owners. Contact
them through a GitHub direct channel (for example a private message to an org
owner listed on the organization's People page) rather than in a public
thread.

The organization owners are responsible for enforcement. They will review
every report promptly, keep the reporter's identity confidential, and apply
the enforcement guidelines in section "Enforcement Guidelines" of the
Contributor Covenant 2.1 (correction, warning, temporary ban, permanent ban).
