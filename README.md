# .github

The HardFOC organisation profile, the community files every repository inherits, and the scripts that keep
repository settings consistent.

**Organisation portal: <https://hardfoc.github.io/>**

| Path | What it is |
| --- | --- |
| [`profile/README.md`](profile/README.md) | The profile shown on <https://github.com/hardfoc> |
| [`CONTRIBUTING.md`](CONTRIBUTING.md), [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md), [`SECURITY.md`](SECURITY.md) | Defaults for every repository without its own |
| [`.github/ISSUE_TEMPLATE/`](.github/ISSUE_TEMPLATE), [`.github/PULL_REQUEST_TEMPLATE.md`](.github/PULL_REQUEST_TEMPLATE.md) | Default issue forms and pull request template |
| [`org/org-metadata.json`](org/org-metadata.json) | Description, homepage and topics of every repository; the portal's catalogue reads it |
| [`org/`](org/README.md) | Scripts that apply the metadata, rulesets, security settings and CODEOWNERS ([guide](org/README.md)) |
